# Анализ современного SEO 2024-2025 и Промпт для Cursor

Привет. Как SEO-эксперт с 10-летним стажем и темщик, я разберу для тебя, как сейчас устроена выдача и дам жесткую инструкцию для твоего ИИ (Cursor), чтобы он переписал код Next.js под максимальный трафик.

---

## Часть 1. Как сейчас работает SEO и как быстро получить трафик

Рынок SEO сильно изменился. Писать портянки текста с вхождением ключей больше не работает.

### Google: Эра E-E-A-T, HCU и Core Web Vitals
1.  **Helpful Content Update (HCU):** Google ненавидит сгенерированный ИИ контент без добавленной стоимости. Контент должен отвечать на интент юзера мгновенно.
2.  **E-E-A-T (Опыт, Экспертность, Авторитетность, Достоверность):** В e-commerce это значит наличие реальных фото, авторов у статей, физического адреса, детальных страниц "О нас" и ссылок на трастовые ресурсы.
3.  **Core Web Vitals:** Техническая скорость. Ваш Next.js должен отдавать первую отрисовку (LCP) быстрее 2.5 сек, а показатель сдвига макета (CLS) должен быть нулевым.
4.  **Фактор брендового трафика:** Google смотрит на объем брендовых запросов ("sotrue", "sotrue доставка").

### Яндекс: Поведенческие факторы (ПФ) и Коммерческие факторы
1.  **Поведенческие факторы:** Это всё для Яндекса. Человек должен зайти на сайт, поскроллить, кликнуть на картинку, нажать "в корзину" и НЕ вернуться в поиск (отказ).
2.  **Коммерческие факторы:** Широта ассортимента (у вас 5.6 млн — это плюс), наличие телефона (обязательно 8-800 или городской), калькулятор доставки, подробные условия оплаты.
3.  **YATI (нейросеть Яндекса):** Яндекс отлично понимает смысл текста. Не нужно спамить "купить кроссовки poizon". Нужно писать "заказать оригинальные кроссовки с доставкой из Китая через байера".

### Стратегия быстрого продвижения: Programmatic SEO
Для 5.6 млн товаров классическое SEO не сработает (не хватит краулингового бюджета). Стратегия:
1.  **Мусор за борт:** Закрываем в `noindex` товары без спроса (no-name бренды, непонятные аксессуары).
2.  **Smart Filters (Умный фильтр):** Это золотая жила. Мы генерируем миллионы посадочных страниц под низкочастотные запросы (НЧ). Пример: `/sneakers/nike/air-force-1/size-42-red`.
3.  **Техничка:** Идеальный `sitemap.xml`, микроразметка `Schema.org`, быстрая загрузка и SSR.

## Часть 2. Промпт для Cursor

Скопируй текст ниже и вставь его в Cursor (желательно использовать Claude 3.5 Sonnet как движок).

```markdown
# ЗАДАНИЕ ДЛЯ CURSOR: ВНЕДРЕНИЕ ПРОДВИНУТОГО SEO ДЛЯ SOTRUE.RU (Next.js App Router)

Ты — Senior Next.js Developer и Technical SEO Expert. Твоя задача — провести глубокую техническую оптимизацию проекта `sotrue.ru` для максимального покрытия низкочастотных и среднечастотных запросов в Google и Яндекс.

Проект использует Next.js App Router. У нас в базе более 5.6 млн товаров.

Реализуй следующие фичи, строго соблюдая лучшие практики Next.js:

## 1. Динамическая генерация мета-тегов (Metadata API)
В файлах `app/product/[id]/page.tsx`, `app/catalog/page.tsx` и `app/brand/[brand]/page.tsx` реализуй экспорт `generateMetadata`:
- **Title:** Должен быть по формуле: `[Название товара/Категории] — Купить оригинал с Poizon | SOTRUE`.
- **Description:** `Купить оригинальный [Название товара] с проверкой Legit Check. Доставка из Китая (Poizon/Dewu) в Россию за 7-18 дней. Размеры в наличии, цена от [Цена] руб.`
- **Open Graph & Twitter Cards:** Настрой `openGraph` и `twitter` объекты, подтягивая `image_url` товара.
- **Canonical URLs:** Добавь тег `<link rel="canonical" href="..." />` с абсолютным путем.

## 2. Внедрение микроразметки Schema.org (JSON-LD)
Используй компонент `next/script` или напрямую добавляй тег `<script type="application/ld+json">` в `<head>` (через Metadata или прямо в JSX).
- **Product Schema (`/product/[id]`):** Разметь название, бренд, картинку, SKU, Offers (Цена в RUB, `priceCurrency`, `availability`: InStock). Укажи `aggregateRating` (если есть данные).
- **BreadcrumbList:** Сделай разметку хлебных крошек для всех страниц каталога и товаров (Главная > Каталог > Бренд > Товар).
- **Organization:** На главной странице разметь компанию (SOTRUE, контактные данные, логотип, соцсети).

## 3. Архитектура Smart Filters (Programmatic SEO)
В каталоге `/app/catalog/page.tsx` нам нужно ловить комбинации фильтров и превращать их в ЧПУ (Человеко-понятные URL), если это популярная комбинация.
- Если юзер выбирает бренд "Nike" и категорию "sneakers", URL должен быть не `?brand=Nike&category=sneakers`, а (опционально для индексации) `/catalog/sneakers/nike`.
- Настрой `robots.txt` и `next.config.js` так, чтобы индексировались только осмысленные комбинации (Бренд + Категория, Бренд + Модель), а глубокие фильтры (например, размер + цвет + цена) были закрыты `noindex`, чтобы не тратить краулинговый бюджет.
- Реализуй генерацию заголовка H1 на основе параметров URL (например, `<h1>Кроссовки Nike оригинальные</h1>`).

## 4. Оптимизация Core Web Vitals (Next/Image & Next/Font)
- Проверь все компоненты `<img>` и замени их на `next/image` (`import Image from 'next/image'`).
- Настрой `next.config.js` (`remotePatterns`) для домена `cdn-poizon-root` (где лежат картинки).
- Для главного изображения товара на `/product/[id]` добавь проп `priority={true}`, чтобы оно грузилось мгновенно и улучшало метрику LCP.
- Убедись, что шрифты грузятся через `next/font/google` или `next/font/local` с настройкой `display: swap`.

## 5. Динамический Sitemap.xml и Robots.txt
- Создай генератор sitemap (т.к. товаров 5.6 млн, нужен sitemap index). В Next.js App Router используй файлы `sitemap.ts` или API роуты для генерации кусков по 50 000 урлов.
- В `robots.txt` закрой системные страницы (`/profile`, `/cart`, `/checkout`, `/api`, `/*?sort=*`) и укажи путь к `sitemap_index.xml`.

## 6. Коммерческие и Поведенческие факторы
- Создай компонент "Социальное доказательство" для карточки товара (имитация "Этот товар сейчас просматривают 5 человек" или "Куплено 12 раз за неделю").
- Убедись, что кнопки "В корзину" и "Оставить заявку" имеют большой размер, контрастный цвет и мгновенный отклик (используй `useTransition` или optimistic UI для плавности).

Начни с внедрения пункта 1 и 2, затем покажи код.
```
